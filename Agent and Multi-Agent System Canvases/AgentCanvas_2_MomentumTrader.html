Agent System Specification Canvas

StockTrader
StockTrader — Momentum Trader (strategy_a). Runs in parallel with Value Contrarian and Volatility Averse (strategy_c) — same data, isolated outputs.
1 System Intent
1
🎯 Use Case / Purpose
Analyze stock market data through the lens of a trend-following investment philosophy — "the trend is your friend." This agent believes rising stocks tend to keep rising and falling stocks tend to keep falling. It is deliberately aggressive, action-oriented, and biased toward BUY and SELL over HOLD. It exists to produce one half of a structured disagreement with the Value Contrarian agent.
2
✂️ Task Slice / Goal
Receive a formatted market data summary for one stock. Apply momentum-based reasoning to produce a structured JSON output: a BUY/HOLD/SELL decision, a confidence score (1–10), and a 3–5 sentence justification that references at least 3 specific data points. The justification must reflect trend-following logic — not generic financial analysis.
3
👥 Users / Stakeholders
Consumer Evaluator agent — receives this agent's decision, confidence, and justification for comparison
Opponent Value Contrarian agent — produces the competing recommendation from the same data (never sees this output)
Reviewer Analyst — inspects JSON outputs to verify behavioral fidelity and data grounding
2 Bounded Behavior
4
⇄ Inputs / Outputs
IN System prompt from prompts/strategy_a.txt + user prompt containing formatted market data (~25 indicators as labeled key-value pairs)
OUT JSON: {"name": "Momentum Trader", "decision": "BUY"|"HOLD"|"SELL", "confidence": 1–10, "justification": "3–5 sentences referencing ≥3 data points"}
5
🔧 Tools / Permissions
ALLOW Anthropic Messages API — one inference call (claude-sonnet-4-6, temperature 0.3, single-shot completion)
DENY yfinance (no independent data access), web search, filesystem, Value Contrarian's output, any tool use or function calling within the LLM call
6
🛡️ Autonomy / Human Checkpoints
Autonomous Full reasoning and recommendation — receives data, produces decision, returns JSON. No human in the loop during execution.
Gated Post-hoc review only: analyst inspects justification quality, verifies data references, checks for personality leakage (contrarian logic appearing in momentum reasoning).
7
📜 Operating Rules / Policies
HARD Must reference ≥3 specific numbers from the data. Decision must be exactly BUY, HOLD, or SELL. Must never see the Value Contrarian's output. Must respond with JSON only.
SOFT Biased toward action (BUY/SELL) over HOLD. Prioritize: MA positions > trend direction > volume > RSI > day ratios. Explicitly ignore: 52-week distances, drawdowns, volatility.
Persona Decisive, action-oriented. Would rather ride a trend and get stopped out than miss a move by overthinking. Personality is encoded in system prompt, not emergent.
Bounded Agentic System
3 Context & Evaluation
8
💾 Memory / Context
Session System prompt + one user message containing formatted market data. Single-turn — no conversation history.
Persist None — each stock analysis is an independent, stateless LLM call. No memory of prior tickers.
Limit ~1,500 tokens input (system + user prompt), ~400 tokens output. Well within Claude Sonnet context window.
Privacy No PII. System prompt is private to this agent — the Value Contrarian and Evaluator never see it.
9
⚠️ Failure Conditions / Escalations
Bad JSON LLM returns non-JSON text → 3-layer parsing fallback (raw → code-block → brace extraction). Retry up to 3× with 1s backoff.
API failure Anthropic API timeout or rate limit → retry up to 3×. After exhaustion, return {"decision": "ERROR", "confidence": 0}.
Generic out Justification doesn't reference specific data → detected post-hoc by analyst review. Indicates prompt needs strengthening.
Persona leak Agent uses contrarian logic (e.g., "overvalued") → detected post-hoc. Indicates prompt boundaries are too weak.
10
✅ Success Criteria
Schema Output parses as valid JSON with all required fields (name, decision, confidence, justification)
Data ground Justification references ≥3 specific numbers from the market data (e.g., "20-day MA of $138.20")
Behavioral Reasoning is identifiably momentum-based — prioritizes trend direction, MA positions, volume. Does not cite 52-week distances or drawdowns.
Divergence Produces a different decision or meaningfully different reasoning than the Value Contrarian on at least 2 of 6 stocks
Consistency Decision aligns with the reasoning — does not say BUY while describing a breakdown in momentum indicators
